# IP 名单模板
#
# 用法：
#   1) 复制本文件，重命名为 ip_list.txt
#   2) 一行一个代理，格式 ip:port（也支持 user:pass@ip:port、http://ip:port）
#   3) 以 # 开头的是注释，空行会被忽略
#   4) 运行：python ip_pool.py    先体检一遍，看有几个真的能用
#
# 提示：免费公开代理存活期通常只有几分钟，检测通过率很低。
#   大规模采集建议用 --proxy-api 让程序自动拉取（见 README）。

# 下面两行是格式示例，把 IP 换成你自己的
127.0.0.1:8080
127.0.0.1:8081

# 需要认证的代理写成这样：
# user:pass@1.2.3.4:8080
