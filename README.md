一个面向**学习与实践**的二手车数据采集项目：双引擎（浏览器自动化 / HTTP 接口）自由切换，内置可插拔 IP 池，一条命令完成「筛选 → 翻页 → 解析 → 落盘」。

> 仅用于个人学习与技术研究，请遵守目标网站的 `robots.txt` 与服务条款，控制请求频率，不要用于商业用途。

# 一、【必做】新手快速上手・最简体验版

这一章只做一件事：**用最快的路线，把你电脑上的第一批车源数据抓下来，存成 CSV 表格。** 全程不开浏览器、不碰代理池、不涉及复杂参数。

## ⚠️ 安全 & 风控提醒（务必先读）

> **requests 指纹更容易被网站识别，本机 IP 高频抓取有被封禁风险。**
>
> - 仅用于**个人学习**，不要用于任何商业用途
> - **降低抓取速度**，页数控制在 1~3 页，不要大批量、成规模地爬取
> - 遵守目标网站 `robots.txt` 的约定
> - **IP 一旦被封，后续你用正常浏览器访问该网站也会受影响**（不只是这个程序用不了）

这一章默认抓 **3 页、约 120 条**，属于轻量试跑，是安全的量级。请不要把 `--pages` 改大。

## 第 0 步（必做）：确认你的电脑装了 Python

先随便打开一个终端窗口（开始菜单搜「命令提示符」就行），输入：

```cmd
python --version
```

**这条命令在干嘛**：让电脑报一下自己装的 Python 版本号。

- 看到 `Python 3.9.x` 或更高版本 → 通过，进入第 1 步
- 看到 `'python' 不是内部或外部命令` → **这就是新手第一大坑：Python 没加入系统环境变量**，请看本章末尾的【踩坑 1】

> 没有 Python 的话，去 <https://www.python.org/downloads/> 下载安装。**安装界面上有一个 `Add Python to PATH` 的勾选框，一定要勾上**，勾了就不会踩上面那个坑。

## 第 3 步（必做）：安装项目依赖

```cmd

```

**这条命令在干嘛**：把项目要用到的第三方库一次性装好（`requests` 负责发请求、`lxml` 负责解析网页、`pandas` 负责组织表格、`openpyxl` 负责写 Excel）。`-r` 的意思是"照着这个文件里列的单子装"。

**这条命令在干嘛**：和上一条完全一样，只是把"下载源"换成清华大学的服务器，国内下载会快很多。

```cmd
python 瓜子二手车_dg.py --engine requests --no-manual --city dg --csv --verbose
```

**这条命令在干嘛**，拆开看：

| 片段 | 作用 |
| --- | --- |
| `python` | 用 Python 运行这个程序 |
| `瓜子二手车_dg.py` | 要运行的主程序文件 |
| `--engine requests` | 用**接口模式**抓（不弹浏览器，速度快） |

## 🚧 新手三大高频踩坑（照着对号入座）

### 踩坑 1：`'python' 不是内部或外部命令`

**现象**：一动 `python` 就报这句红字。

**原因**：装 Python 时**没勾 "Add Python to PATH"**，系统不知道 `python` 这个程序在哪。

**解决**：
1. 重新跑一遍 Python 安装包，选 **Modify**，把 `Add Python to PATH` 勾上
2. 或者手动加：`此电脑 → 右键属性 → 高级系统设置 → 环境变量 → 系统变量里的 Path → 编辑 → 新建 →` 把 Python 安装目录（比如 `C:\Python313\`）和它下面的 `Scripts` 目录（`C:\Python313\Scripts\`）都加进去
3. **改完必须关掉终端重新开一个**，旧窗口不会生效

### 踩坑 2：文件夹路径里有中文或空格

**现象**：各种奇怪的 `SyntaxError`、`找不到文件`、库导入失败。

**原因**：部分 Python 库和命令行工具对中文路径、空格路径支持不好，会解析出错。

**解决**：把整个项目文件夹挪到一个**纯英文、无空格**的路径下，比如：

- ✅ 可以：`C:\guazi`、`D:\projects\guazi`、`C:\Users\fyh\Desktop\guazi`
- ❌ 避免：`C:\我的项目\爬虫\`、`D:\课程 作业\guazi`

挪完重新打开终端，回到第 2 步。

### 踩坑 3：终端开在了错误的目录

**现象**：敲命令报 `can't open file '瓜子二手车_dg.py': [Errno 2] No such file or directory`。

**原因**：终端当前所在的文件夹里**根本没有这个文件**，常见于直接双击"命令提示符"图标打开的默认窗口（它会停在 `C:\Users\你的用户名>`）。

**解决**：两种办法

1. 重新按第 2 步，在项目文件夹的地址栏里输入 `cmd` 回车
2. 或者在现在的终端里手动切过去（把路径换成你自己的）：

```cmd
cd /d C:\Users\fyh\Desktop\guazi
```

**这条命令在干嘛**：`cd` 是"切换文件夹"，`/d` 是"连盘符一起切"（从 C 盘跳到 D 盘时必须加，否则切不过去）。

切完再运行一次 `dir`，确认能看到 `瓜子二手车_dg.py`。

# 二、【可选进阶】浏览器模式（Playwright）

## 什么时候你需要它

requests 模式虽然快，但有三个绕不过去的限制：

1. **指纹固定**，容易被识别成机器，抓几页就开始返回验证页
2. **网站改版后 filter 参数对不上**，你可能拼不出正确的 URL
3. **滑块验证码**在纯接口模式下没法过

浏览器模式就是让程序**开一个真的浏览器**去访问。它能：

- 由你在页面上**手动点筛选条件**（品牌、价格、年份），程序照抄你的地址栏，不猜 URL 规则
- 执行页面里的所有 JavaScript，和真人浏览器没有区别
- 遇到验证码时，**你可以在那个窗口里手动过掉**

## 准备：下载浏览器内核（首次必须）

```cmd
python -m playwright install chromium
```

**这条命令在干嘛**：下载 Playwright 专用的小型 Chromium 浏览器（约 150 MB）。**只有浏览器模式需要，requests 模式不用装。**

**下不动怎么办**（很常见）：不用管它，程序内置了三级回退——找不到自带 Chromium，会自动改用你电脑上已有的 **Microsoft Edge**，再不行用 **Google Chrome**。只要这三个里有任意一个，就能跑。

## 用法一：手动筛选模式（推荐给新手）

```cmd
python 瓜子二手车_dg.py
```

**这条命令在干嘛**：不加任何参数，走默认的浏览器模式。

运行后会发生这几件事：

1. 弹出一个**看得见的**浏览器，停在瓜子东莞列表页
2. **你自己在页面上点**城市、品牌、价格、年份这些筛选条件
3. 回到终端按一下 **Enter**，程序读取当前地址栏作为抓取起点
4. 浏览器**不关闭**，在同一个会话里一页页往下翻（Cookie 和登录状态全程保持）
5. 抓完自动保存 Excel，然后关掉浏览器

> 为什么这条路线最稳：瓜子的筛选是"页面跳转 + JS 渲染"出来的，URL 规则不统一。让你亲手点一遍、程序照抄地址栏，是**最不容易拼错**的方式。

## 用法二：无头模式（不弹窗口，静默抓）

```cmd
python 瓜子二手车_dg.py --engine playwright --no-manual --headless --pages 5
```

**这条命令在干嘛**：用浏览器引擎，但**不显示窗口**（`--headless`），跳过手动筛选（`--no-manual`），抓 5 页。

适合你已经知道要抓哪些条件、不想看着它慢慢翻的场景。

# 三、【可选进阶】IP 代理池

## 什么时候需要它

**当你的本机 IP 被网站拉黑了。** 典型信号：

- 程序突然开始返回验证页或者空页面
- 换 WiFi、换手机热点都不管用
- 用**正常的浏览器**手动访问该网站，也被拦或者打不开

这时候唯一的出路就是：**别用你自己的 IP，改用别人的 IP 去访问**。IP 池干的就是这件事。

## 它到底在做什么

```
api_url.txt ──请求──▶ 代理服务商 ──▶ 返回 10 个 ip:port
                                          │
                                          ▼
                             逐个真发一次请求检测（不是只 ping 通）
                                          │
                        ├─ 200 且页面含关键元素 ──▶ 进池
                        └─ 超时 / 拒绝 / 被拦 / 兜底页 ──▶ 丢弃

抓取：第 1 页 → 池里第 1 个 IP
      第 2 页 → 池里第 2 个 IP        （默认顺序轮换，相邻页不撞同一 IP）
      某页失败 → 换下一个 IP 重试（最多 4 次）
      同一 IP 连败 3 次 → 踢出池子
      池子被踢空 → 自动再调一次 API 补货
```

## 准备：填好 API 链接

1. 复制模板文件：

```cmd
copy api_url.example.txt api_url.txt
```

**这条命令在干嘛**：把一个"示例模板"复制成正式的配置文件（`api_url.txt` 已经被 `.gitignore` 挡掉，**填了密钥也不会传到 GitHub**）。

2. 用记事本打开 `api_url.txt`，把里面那行替换成你的代理服务商 API 链接，保存。

> 这个文件里会放你的真实密钥。**永远不要**把它改名、也不要手动 `git add` 它，`.gitignore` 已经帮你挡着了。

## 用法：一条命令拉 IP + 检测 + 轮换抓取

**接口模式挂池（大批量场景）**

```cmd
python 瓜子二手车_dg.py --engine requests --no-manual --city dg --proxy-api
```

**这条命令在干嘛**：`--proxy-api` 会自动串起整套流程 —— 调 API 拉新 IP → 逐个检测 → 剔除死 IP → 建池 → 每页换一个 IP 抓取 → 池空自动补货。你不需要手动维护名单。

**浏览器模式挂池（本机 IP 已封、但还需要过验证码时用）**

```cmd
python 瓜子二手车_dg.py --engine playwright --no-manual --headless --pages 20 --proxy-api
```

**这条命令在干嘛**：让**浏览器本身**走代理（代理挂在 `browser.new_context(proxy={...})` 上）。换 IP 时只重建一个上下文、不重启浏览器进程，实测零点几秒；旧 Cookie 会迁移过去，**已经过掉的滑块验证不会因为换 IP 而作废**。

## 用自己准备的 IP 名单（不想用 API）

```cmd
python 瓜子二手车_dg.py --engine requests --no-manual --city dg --proxy --proxy-file my_ips.txt
```

**这条命令在干嘛**：`--proxy` 启用 IP 池，`--proxy-file my_ips.txt` 指定名单文件。文件格式很简单，一行一个：

```
1.2.3.4:8080
5.6.7.8:3128
```

模板见 `ip_list.example.txt`。

## 三条实测经验（很重要）

1. **只测"能不能连上"是不够的**。必须对目标网站**真发一次请求**，并检查页面里有没有关键元素——否则被风控返回的兜底页，也会被当成"可用 IP"混进池子。
2. **短效代理的存活期是分钟级**。实测拉取后立刻测，约 7~9/10 可用；8 分钟后再测只剩 3/10。所以**每次运行都要重新拉，不要复用上次的名单**。
3. **挂了 IP 池不等于可以猛抓**。代理 IP 也是别人的资源，跑太猛一样会被封，而且可能影响同一 IP 上的其他用户。控制页数，别贪。

详细实测数据与排障方法见 [docs/IP池使用说明.md](docs/IP池使用说明.md)。

# 四、全部命令参数说明

## 基础参数

| 参数 | 默认值 | 说明 |
| --- | --- | --- |
| `--engine` | `playwright` | 抓取引擎：`playwright`（浏览器）/ `requests`（接口） |
| `--pages` | `3` | 抓取页数。`0` = 抓到没有房源为止（**网站上限 20 页**，第 21 页起返回空） |
| `--manual` / `--no-manual` | `--manual` | 是否在浏览器里手动点筛选。默认要手动 |
| `--headless` | 关 | 无头模式（不弹窗口）。仅 `--engine playwright` 配合 `--no-manual` 时生效 |
| `--verbose` | 关 | 打印请求细节：HTTP 状态码、HTML 长度、重试过程、当前用的哪个 IP |
| `--csv` | 关 | **额外**导出一份 CSV（不加只出 Excel） |

## 筛选参数

| 参数 | 默认值 | 说明 |
| --- | --- | --- |
| `--city` | `dg` | 城市拼音路径：`dg` 东莞 / `gz` 广州 / `sz` 深圳 / `fs` 佛山 |
| `--brand` | 无 | 品牌路径段，如 `bmw`。仅 `--no-manual` 时生效 |
| `--price-min` / `--price-max` | 无 | 价格区间（万元）。会先映射到最接近的官方价格档位，抓完再在本地精确过滤 |
| `--price-code` | 无 | 直接用网站的价格档位 `0~15`，如 `6` 约等于 5 万档 |
| `--extra-query` | 无 | 通用 query 透传，如 `"year=2018-2020&fuel=汽油"` |

## IP 池参数

| 参数 | 默认值 | 说明 |
| --- | --- | --- |
| `--proxy` | 关 | 启用 IP 池（读 `ip_list.txt`，先检测再使用） |
| `--proxy-file` | `ip_list.txt` | 指定代理名单文件，一行一个 `ip:port` |
| `--proxy-api` | 关 | 建池前先调服务商 API 拉一批新 IP（链接写在 `api_url.txt`） |
| `--proxy-rotate` | `round` | 取 IP 策略：`round` 顺序轮换 / `random` 随机取 |
| `--proxy-workers` | `10` | IP 并发检测线程数 |
| `--no-proxy-check` | 关 | 跳过建池检测，全部 IP 直接进池（快，但会带着坏 IP 跑） |

## 其他

| --- | --- |
| `--no-fallback` | 关闭「requests 彻底失败时临时开一次浏览器救这一页」的兜底行为 |

# 七、技术说明

## 双引擎怎么选

| 维度 | `playwright`（浏览器） | `requests`（接口） |
| --- | --- | --- |
| 反爬对抗 | **强**，真实浏览器指纹、Cookie、JS 全执行 | 弱，靠请求头与访问频率伪装 |
| 速度 | 慢，每页 2~5 秒 | **快**，每页 < 1 秒 |
| 依赖 | 需浏览器内核（或系统 Edge / Chrome） | 仅需 Python 库 |
| 能挂 IP 池 | ✅ 每页可换 IP（上下文级代理） | ✅ 每页可换 IP |
| 适合场景 | 少量精准采集、筛选条件复杂、要过验证码 | 大批量静默采集 |

**两者都能挂 IP 池**，区别只在"代理挂在哪"：requests 挂 `proxies={...}`，浏览器挂 `new_context(proxy={...})`。

## 反爬处理

- **随机延时**：每页之间随机等 2~5 秒，失败重试时等 8~15 秒
- **失败重试**：同一页最多重试 4 次，每次换 IP（挂了池的话）
- **兜底页识别**：返回内容里找不到关键元素时，判定为被风控拦了，当成失败处理
- **验证页识别**：返回内容里出现验证提示，判定为被拦
- **Cookie 复用**：浏览器模式全程同一个会话，抓取途中不丢登录态

## 浏览器启动回退链

找不到 Playwright 自带的 Chromium 时，按这个顺序自动降级：

1. 自带 Chromium
2. 系统 **Microsoft Edge**
3. 系统 **Google Chrome**

三者都没有才报错。所以多数 Windows 电脑**不需要**下载那 150 MB 内核。

## 一个踩过的坑（给以后改代码的你）

**Edge 无头模式下 `goto` 常常等不到 `domcontentloaded` 事件，直接抛超时，但页面其实已经加载完了。** 所以主程序里统一用 `wait_until="commit"`（只等服务器开始返回就继续），再自己轮询 `page.content()` 判断内容是否到位。

不这么改的话，会稳定出现"日志显示卡片 0 个、但其实解析出了 40 条"这种假阴性。

# 八、常见问题

**Q：报错提示缺少浏览器内核 / playwright 相关错误？**

如果你跑的是 `--engine requests`，这个错误说明触发了兜底逻辑（接口失败时想开浏览器救这一页）。两种选择：装内核，或者加 `--no-fallback` 关掉兜底。

```cmd
python -m playwright install chromium
```

**Q：报 `ImportError` 说 `cssselect` 找不到？**

`lxml` 用 CSS 选择器时需要它，单独补装：

```cmd
pip install cssselect
```

**Q：抓到了 0 条，或者日志里卡片数是 0？**

大概率被风控拦了，返回的是兜底页。处理顺序：

1. 加 `--verbose` 看最终 URL 和 HTML 长度
2. 如果跳到了验证页 → 降频率、减页数
3. 还是不行 → 换 `--engine playwright`（浏览器模式），或者挂 IP 池

**Q：翻到第 21 页就没数据了？**

不是 bug。网站本身的分页上限实测是 **20 页**，第 21 页起返回空。

**Q：为什么翻页要用 `?page=2`，不能用 `/pg2/`？**

路径段形式实测会 404，只有 query 形式有效。参数里已经处理好了，你不用管。

**Q：浏览器也能挂 IP 池吗？**

能。代理挂在 `browser.new_context(proxy={"server": "http://ip:port"})` 上，换 IP 只关掉旧上下文再开个新的，不重启浏览器进程（实测零点几秒）。旧上下文的 Cookie 会搬到新上下文，已经过掉的滑块验证不会因为换 IP 而失效。

**Q：结果文件能传到 GitHub 吗？**

会自动被挡掉，不用手动排除。`.gitignore` 里已经写了 `瓜子二手车_*.xlsx` / `*.csv`。
