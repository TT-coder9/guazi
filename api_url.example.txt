# 代理 API 链接模板

# 用法：
#   1) 复制本文件，重命名为 api_url.txt（不带 .example）
#   2) 把下面的占位符换成你自己的真实链接
#   3) 运行：python proxy_api.py --dry-run    验证能不能拉到手
#
# 注意：
#   · api_url.txt 已在 .gitignore 中，不会被提交到仓库

#   · 更稳妥的做法是改用环境变量 PROXY_API_URL（见 docs/IP池使用说明.md）
